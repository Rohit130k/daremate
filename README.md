# 🎮 DareMate

Premium real-time Truth or Dare experience.

## ✨ Features
- **Elite UI:** Glassmorphism, premium typography, and smooth animations.
- **Private Rooms:** Unique 6-digit access codes for private sessions.
- **Real-time Sync:** Powered by Socket.IO for seamless multiplayer interaction.
- **Dynamic Content:** Curated Truth & Dare categories (Funny, Romantic, Spicy, Emotional).
- **Mobile First:** Designed to look stunning on every device.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- npm

### 2. Installation

#### Backend
```bash
cd server
npm install
npm run dev
```

#### Frontend
```bash
cd client
npm install
npm run dev
```

### 3. Environment Setup
Create a `.env` in the `server` folder:
```env
PORT=5000
MONGODB_URI=your_mongodb_uri (optional)
```

## 🛠️ Stack
- **Frontend:** React, Tailwind CSS v4, Framer Motion, Lucide Icons.
- **Backend:** Node.js, Express, Socket.IO.
- **Database:** MongoDB (via Mongoose).
