🎨 Design Style Guide (IMPORTANT)
🎯 Theme:
Dark gradient (Purple → Blue)
Neon highlights
🔤 Font:
Headings: Bold (Poppins / Inter)
Body: Clean readable
🔘 Components:
Rounded buttons (12–16px radius)
Soft shadows
Smooth transitions
🧠 UX Best Practices
One-thumb usage (bottom-heavy UI)
Minimum typing
Instant feedback (animations)
Fast transitions (no loading feel)
